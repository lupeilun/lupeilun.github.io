Privacy Policy — C40B Drive Bridge

Last updated: October 23, 2026

1. About This Application

C40B Drive Bridge is a personal, single-user utility that allows its owner to exchange task instructions and response files between a personal computer and the owner’s Google Drive.

The application is intended exclusively for the owner’s personal use. It is not offered as a commercial service or a public application for other users.

2. Google User Data Accessed

With authorization from the owner, the application can access files and information in the owner’s Google Drive through the Google Drive API.

The OAuth authorization may permit access to a broader range of Drive files than the specific documents currently processed by the utility.

In normal operation, the utility uses designated task documents and response files to exchange information with the owner’s computer.

The application does not request access to other people’s Google accounts.

3. How Google User Data Is Used

Google Drive data is used to:

* Read task instructions authorized by the owner.
* Process supported tasks on the owner’s computer.
* Create, read, and verify response files.
* Prevent duplicate processing and maintain task execution records.

Google user data is not used for advertising, marketing, or profiling.

The application does not sell Google user data.

4. Storage and Security

Task instructions, response files, and execution records may be stored on the owner’s computer and in the owner’s Google Drive.

Google OAuth credentials are stored in the owner’s local application configuration and are not intentionally published or included in the informational website.

Access to the owner’s computer and Google Drive account is managed by the owner.

No security system can guarantee absolute protection against unauthorized access.

5. Data Sharing and Transfers

The utility is not designed to sell or distribute Google user data to unrelated third parties.

The utility uses Google’s services to access and store the owner’s Google Drive files.

Task and response data may also be accessed through other services separately authorized by the owner as part of the owner’s personal workflow.

This website does not itself operate a separate service for collecting or processing Google Drive contents.

6. Data Retention and Deletion

Task files, response files, and local execution records may remain in storage until the owner deletes them or authorizes their removal.

The utility does not currently promise automatic deletion after a fixed retention period.

The owner can remove files from Google Drive, delete locally stored records, and revoke the application’s access through Google Account settings.

7. Revoking Google Access

The owner may revoke the application’s access at any time through the Google Account third-party connections page:

https://myaccount.google.com/connections

Revoking access prevents further authorized Google Drive API operations unless the application is authorized again. Previously stored files and local records may need to be deleted separately.

8. Public Website

This website is hosted using GitHub Pages and provides information about the utility.

The website does not provide account registration, an application login, or forms for submitting personal information.

GitHub may process technical information associated with delivering this website in accordance with its own privacy policies.

9. Google API Services User Data Policy

The application’s use and transfer of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including applicable Limited Use requirements.

Google user data is accessed only for the owner’s authorized purposes and is not sold or used to serve advertisements.

10. Changes to This Policy

This policy may be updated if the application’s functionality, Google API access, or data-handling practices change.
